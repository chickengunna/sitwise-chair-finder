# Sitwise — Chair Finder

An interactive office-chair finder: answer seven short questions and the chairs in the grid re-sort by how well they match. Plain HTML/CSS/JS, no build step. All chairs are fictional.

## Run

```bash
python -m http.server 5173
```

Then open http://localhost:5173.

## Files

- `index.html`, `style.css`, `app.js` — UI and logic
- `data.js` — chairs, questions, scoring
- `chair-svg.js` — procedural chair illustrations

Languages: English and Russian (switch in the "…" menu).
